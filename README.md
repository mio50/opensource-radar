[معاينة مباشرة](https://osradar-bxm3b78u.manus.space) · [الإبلاغ عن مشكلة](https://github.com/mio50/opensource-radar/issues)

## الفكرة

يحول **OpenSource Radar** الضوضاء الكبيرة في GitHub إلى فرص مساهمة قابلة للبدء. يلتقط المستودعات التي لديها قضايا موسومة بـ `good first issue` أو `help wanted`، ثم يحسب درجة تطابقها مع لغات المستخدم واهتماماته وخبرته، ويوضح له كيف يبدأ بصورة عملية.

## ما الذي يقدمه؟

| الميزة | الوصف |
| --- | --- |
| بحث حي من GitHub | يكتشف مستودعات تملك فرص مساهمة مفتوحة باستخدام مؤشرات القضايا المناسبة للمساهمين. |
| مطابقة مهارات | يقارن اللغة والمواضيع والوصف بمهارات المستخدم ويعرض نسبة توافق لكل مشروع. |
| فلاتر دقيقة | تصفية النتائج بحسب اللغة، المستوى، والحد الأدنى للنجوم. |
| إرشاد ذكي | يشرح لماذا يناسب المشروع المستخدم ويقترح خطوات بداية آمنة وقابلة للتحقق. |
| حسابات ومفضلة | يحفظ الملف المهاري والمشاريع المفضلة للمستخدمين المسجلين. |
| واجهة عربية بروتاليستية | RTL كامل وهوية داكنة عالية التباين بالألوان الأسود والأبيض والأحمر. |

## التقنية

المشروع مبني باستخدام **React 19** و**TypeScript** و**Tailwind CSS 4** في الواجهة، و**Express + tRPC** في الخادم، مع **Drizzle ORM** وقاعدة بيانات MySQL/TiDB للملفات الشخصية والمفضلة. يعمل البحث عبر GitHub REST API، ويُشغّل الإرشاد المخصص من الخادم باستخدام نموذج لغوي مدمج.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

للتأكد من جودة الكود:

```bash
pnpm test
pnpm check
```

## متغيرات البيئة

يعمل البحث مع GitHub دون رمز وصول ضمن الحدود العامة، لكن يُستحسن تعيين `GITHUB_TOKEN` في بيئة الإنتاج لرفع حدود الطلبات. بقية المتغيرات الخاصة بالمصادقة وقاعدة البيانات والنموذج اللغوي يوفرها قالب المنصة.

## المساهمة

نرحب بالاقتراحات والإصلاحات. افتح **Issue** يوضح المشكلة أو اقتراحك، ثم أرسل **Pull Request** صغيرًا ومركزًا بعد التأكد من تشغيل الاختبارات وفحص الأنواع.

## الترخيص

لم يُحدد ترخيص للمشروع بعد. قبل استخدامه أو إعادة توزيعه، يرجى التواصل مع مالك المستودع أو إضافة ملف ترخيص مناسب.
